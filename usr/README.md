# Presentación Avícola - Santa Rosa de Conlara

Este proyecto es una aplicación interactiva desarrollada en Flutter, diseñada para funcionar como un Pitch Deck (Carpeta de Presentación) para el proyecto avícola en Santa Rosa de Conlara, San Luis. Su objetivo es facilitar la presentación ante autoridades provinciales y entidades financieras.

## Características Principales

*   **Visión General:** Resumen del proyecto, sus objetivos (120,000 ponedoras) y la ubicación estratégica.
*   **Fases de Crecimiento:** Detalle del inicio con un galpón (30,000) y la proyección a cuatro galpones con diferentes edades de aves.
*   **Economía Circular:** Explicación del tratamiento de residuos (compostaje de aves) y producción de fertilizante a partir de guano.
*   **Infraestructura Completa:** Detalles de la planta de alimentos, galpón de recría, planta de clasificación y logística.
*   **Solicitud de Crédito y Sustentabilidad:** Enfoque especial en la implementación de energía solar para alimentar la granja de forma sustentable.
*   **Generación de Empleo:** Proyección del crecimiento de puestos de trabajo.

## Tecnologías Utilizadas

*   **Flutter:** Framework principal para asegurar un rendimiento nativo fluido en Android, iOS y Web.
*   **Material 3:** Sistema de diseño para una interfaz moderna, limpia y profesional.
*   **Google Fonts:** Tipografía optimizada para lectura en presentaciones.

## Ejecución

Para correr el proyecto localmente:

```bash
flutter run
```
